# AI Paste Guard

AI Paste Guard is a Chrome extension that checks text you paste into ChatGPT,
Claude, and Gemini on your device. If the text contains a high-confidence secret,
such as an API key, token, private key, or a password in a connection string, it
pauses the paste so you can redact it, cancel, or paste anyway. It has no account,
no analytics, and makes no network requests.

This public repository hosts AI Paste Guard's [privacy policy](PRIVACY.md),
[support information](SUPPORT.md), and Chrome Web Store images in
[`assets/`](assets/). The extension's feedback links open issues here. It does not
contain the extension source or release zip.

AI Paste Guard can't catch every possible secret, and it does not check typed
text, files, images, iframes, or other sites. It is independent and is not
affiliated with or endorsed by OpenAI, Anthropic, or Google.
