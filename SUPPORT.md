# AI Paste Guard support

For help, feedback, a false alarm, or a missed secret,
[open an issue](https://github.com/mohdashraf010897/ai-paste-guard-public/issues/new)
in this public repository. A GitHub account is required to post. The extension's
"Send feedback", "Report a missed secret", and "Report a false alarm" links open a
prefilled issue here with only the extension version, rule IDs, and site.

Please include your Chrome version, the AI Paste Guard version, the site, what you
expected, and what happened. Describe a secret's format in words (for example its
prefix and length).

**Never paste a real secret, API key, token, password, or the text you pasted into an
issue.** Issues are public. If you shared a real secret anywhere, rotate it with its
provider.

For details about what the extension reads and stores, read the
[privacy policy](PRIVACY.md).
